# Mason Neuenschwander Portfolio V1

Current scope:
- Home: intro, professional photo, Resume, LinkedIn
- Projects: interactive Truckload Margin & Cost Analysis Power BI report + case study
- Contact: email, phone, Resume, LinkedIn

The professional photo is `profile.png`.
The final resume is `resume.pdf`.
The Power BI public embed link is already included.

## Preview locally
Fully extract the ZIP first, then open `index.html`.

Keep these files together in the same folder:
- index.html
- styles.css
- script.js
- profile.png
- resume.pdf

## Publish
Upload the entire extracted folder to your static host.
