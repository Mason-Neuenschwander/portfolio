Truckload Margin & Cost Analysis

An interactive Power BI analysis using synthetic shipment data in the Truckload mode to analyze profitability, compare carrier costs, model margin targets, and prioritize lanes for follow-up. The goal is to give the Carrier Sales and Pricing teams a clear path from identifying a problem to deciding what to review.

CASE STUDY — TRUCKLOAD MARGIN & COST ANALYSIS Expand +

Where are carrier costs hurting margin, how much opportunity exists, and what action should we take?

1. Margin Performance Overview Show more

Establishes the financial picture first. The page shows weighted margin performance by customer, lane, and month, along with revenue, carrier cost, shipment volume, and low-margin lanes so the user can quickly see where performance is strongest and weakest in the Truckload mode.

2. Opportunity Model Show more

Gives the user a what-if modeling board instead of forcing one fixed target. After selecting a lane and target margin, the report calculates the carrier cost required to reach that target margin while holding revenue constant. This allows Carrier Sales and Pricing teams to test different margin targets by lane and see what carrier cost would be required to make those targets possible. The resulting modeled opportunity can help frame carrier negotiations and identify where cost reductions may be worth pursuing. Modeled opportunity is not guaranteed savings, but provides a practical estimate of what carrier cost would need to be to achieve the selected financial target.

3. Priority Lane Action Plan Show more

The Priority Lane Action Plan turns the profitability analysis into a lane-level review process, with priority rankings. Each lane is evaluated using its current margin, Median-Benchmark Opportunity, and the number of loads that moved with carriers priced above the lane benchmark. The Median-Benchmark Opportunity is more conservative than the what-if model on Page 2 because it uses the lane’s own historical carrier-cost performance as the benchmark instead of a user-selected margin target. That makes it more realistic for prioritization because the median reflects a cost level that has already been achieved on the lane, without assuming every carrier can be pushed to the lowest observed rate. The page uses these factors to rank lanes by priority with a recommended action, and also lets Carrier Sales and Pricing teams review the individual carriers contributing to the opportunity.

$ Median-Benchmark Opportunity

Each carrier's average cost per load is compared with the median carrier average cost on the same lane for the selected period. When a carrier is above that benchmark, the excess cost per load is multiplied by that carrier's load count. Those amounts are summed to estimate the lane's modeled opportunity. It is an analytical benchmark, not guaranteed savings.

Priority Ranking

Priority is calculated using defined margin and opportunity thresholds.

A lane is classified as High Priority when its margin is below 11%, or when its margin is below 15.5% and Median-Benchmark Opportunity is at least $900. These lanes rank highest because they show the strongest combination of weak profitability and meaningful cost opportunity. The recommended action is Prioritize Carrier Mix Review, focusing attention on whether carrier selection or rate structure should be changed.

A lane is classified as Medium Priority when margin is below 18%, opportunity is at least $350, and at least five loads moved above the benchmark, or when margin is below 19% and opportunity is at least $750. These lanes still show worthwhile improvement potential, but the margin pressure or opportunity is less severe. The recommended action is Validate Carrier Cost Improvement, meaning the user should confirm whether the modeled opportunity is realistic before taking action.

Any remaining lane with benchmark opportunity is classified as Low Priority. These lanes show some cost opportunity, but not enough financial pressure to justify immediate action. The recommended action is Monitor Carrier Spread. Lanes with no benchmark opportunity receive No Action, indicating that the current carrier-cost profile does not show a meaningful opportunity based on the model.

Tools

The project was built in Power BI using DAX and Power Query.

Data Note

This project uses synthetic freight data created for portfolio demonstration purposes, with realistic transportation patterns modeled to support the analysis. No proprietary company, customer, or carrier data is included.
